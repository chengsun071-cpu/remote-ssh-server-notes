# VS Code Remote-SSH 连接超算服务器配置记录

## 一、文档说明

本文记录在 Windows 本地电脑上，使用 VS Code Remote-SSH 远程连接超算服务器的完整过程，包括 SSH 配置、密钥登录、VS Code Server 初始化、常见问题排查以及后续代码编辑流程。

通过 Remote-SSH，可以在本地 VS Code 中直接打开服务器上的项目目录，修改服务器代码，并在服务器环境中运行命令，避免频繁手动上传代码。

---

## 二、使用场景

传统方式通常是：

```text
本地改代码
↓
手动上传服务器
↓
服务器运行
↓
再下载日志或结果
